# 👁️ Herobrine Desktop Pet

A Minecraft Herobrine-inspired desktop companion built with Python. He walks around your desktop, teleports randomly, watches your mouse cursor, talks to you using AI, and occasionally surprises you!

## ✨ Features

- 🚶 **Walking Animation** – Herobrine moves around your desktop.
- 🌀 **Random Teleportation** – He can suddenly disappear and reappear somewhere else.
- 💬 **Speech Bubbles** – Herobrine can communicate with you.
- 🧠 **Memory System** – Remembers previous conversations.
- 🖱️ **Mouse Tracking** – Watches your cursor movements.
- 👻 **Jumpscares** – Occasional spooky surprises.
- 🔊 **Minecraft Sound Effects** – Includes Minecraft-inspired sounds.
- 🧗 **Wall Crawling** – Herobrine can crawl around desktop edges.
- 🤖 **Ollama AI Integration** – Chat with Herobrine using a locally running AI model.

## 🖥️ Requirements

- Windows 10 or Windows 11
- Python 3
- Ollama
- A downloaded Ollama language model (Llama 3 recommended)

## 📦 Installation

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Herobrine-Desktop-Pet
```

### 3. Install dependencies

```bash
pip install pygame pyautogui pillow requests psutil
```

Install any additional dependencies listed in `requirements.txt`.

### 4. Install Ollama

Download Ollama:

https://ollama.com/download

Pull the Llama 3 model:

```bash
ollama pull llama3
```

### 5. Run Herobrine

```bash
python herobrine.py
```

## ⚙️ Configuration

You can customize Herobrine's behavior, including:

- Teleportation frequency
- Animation speed
- Jumpscare frequency
- Sound effects
- AI model

## 🤖 AI Integration

This project uses Ollama to run AI locally.

The default model is:

```text
llama3
```

Make sure Ollama is running before launching the desktop pet.
